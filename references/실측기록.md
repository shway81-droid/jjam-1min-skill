## CLI는 왜 못 썼나

`notebooklm-py` 를 0.4.1 → **0.8.2** 로 올렸고 `generate video --format short` 가 실제로 있다.
그런데 인증이 막혔다.

- `gmail` 프로필 쿠키가 만료됨 (마지막 로그인 9/14) → `Authentication expired or invalid`
- `auth inspect --browser chrome` 은 크롬 쿠키를 읽지만 **"too stale"** — Aside 브라우저는 별도 프로필을 쓴다
- Aside `page` 에 `context()`·`cdp` 가 없어 쿠키를 꺼낼 수 없다

→ 사람이 한 번 로그인하면 CLI 경로가 열린다. 그때까지는 브라우저 UI가 정답이고,
**세션 만료 걱정이 없다는 점에서 오히려 낫다.**

### 환경 함정

Aside 셸은 `PYTHONHOME`·`PIP_PREFIX` 를 자기 런타임으로 걸어 둔다.
다른 파이썬을 `& $py -m pip` 로 부르면 pip이 깨지거나 패키지가 Aside 쪽에 깔린다.
Aside에서 쓸 것은 그냥 `pip install` 로 깐다.

또 간헐적으로 `[SSL: CERTIFICATE_VERIFY_FAILED] EE certificate key too weak` 가 난다.
재시도하면 통과한다. `raw.githubusercontent.com` 도 같은 증상이라 GitHub raw는
`api.github.com/repos/.../contents/` 로 우회했다.

# 1단원 마무리 (2026-09-22)

## 현황 — 영상 17편 완성, 공개 15편

| 상태 | 차시 |
|---|---|
| 유튜브 공개 + 사이트 등록 | 01 02 03 04 05 06 07 08 09 10 12 13 14 16 17 (15편) |
| mp4 완성, 업로드 대기 | **19** (1:31) · **20** (1:28) |

1단원 17차시 영상은 모두 만들었다. 남은 것은 유튜브 업로드와 사이트 등록뿐이다.

## 유튜브 일일 한도는 달력이 아니라 이동 24시간이다

9/21 12:05~16:55 사이에 15편을 올려 한도에 닿았다. **다음 날 오전 8:47 에도 여전히 막혀 있었다** —
달력 날짜가 바뀌어도 풀리지 않는다. 직전 24시간 안의 업로드 수를 세기 때문이다.
첫 자리는 12:05 경, 전부는 17:00 경에 풀린다.

풀려면 채널 전화번호 인증(일회성)을 하면 된다. 2·3단원 26편을 하려면 이게 먼저다.

## 20차시 검수 — 쓸 수는 있으나 결함 3가지

88초, 720x1280, 종이공예 디오라마 스타일. 1단원 흐름을 순서대로 짚는다.

1. **청동기 인물이 투구와 갑옷을 갖춘 전사로 나온다.** 교과서 청동기 시대에 그런 갑옷은 없다
   (철제 판갑옷은 가야다). 프롬프트에 "그 시대에 없던 물건을 그리지 마세요"가 있는데도 나왔다.
2. **통일신라 불교 장면에 조선식 한복과 기와집이 나온다.** 색동 저고리는 통일신라 복식이 아니다.
3. **마지막 자막이 '5s' 로 깨졌다.** 한국어가 아닌 글자다. "화면 글자는 모두 한국어" 조항 위반.

단원 마무리라 여러 시대를 빠르게 넘기는 차시인데, 시대별 복식·무장을 구분하는 데는
약한 것으로 보인다. **재생성 후보 1순위다.**

## 함정 하나 더

**유튜브 업로드의 setFiles 는 세션 폴더 안의 파일만 받는다.**
작업 폴더(output/)의 mp4 를 바로 주면 Path escapes the session directory 로 막힌다.
세션 tmp 로 복사한 뒤 올린다. NotebookLM 소스 업로드와 같은 제약이다.

## 중간에 바뀐 큰 규칙 — 차시마다 두 편

한 편만 만들면 결함이 있어도 그것을 쓸 수밖에 없다는 것이 20차시에서 드러났다.
1편에 결함이 셋(청동기 인물의 투구와 갑옷, 통일신라 장면의 조선식 색동 한복,
마지막 자막이 `5s` 로 깨짐) 있었는데 고를 다른 편이 없었다.

그래서 **같은 프롬프트로 두 편을 만들어 유튜브에 둘 다 올리고, 사이트에 걸 한 편은
사용자가 고르는** 방식으로 바꿨다.

## 마지막에 풀린 것 둘

- **유튜브 고급 기능** — 전화번호 인증만으로는 안 되고 3단계 고급 기능이 필요했다.
  영상 인증을 제출해 `대기 중` 이 됐고, **2026-09-23 에 승인됐다.**
  이로써 「24시간에 10~15편」 제약이 걷혔고, 남은 병목은
  **NotebookLM 생성 쪽**이다(5시간 창에 10~11편).
  승인 뒤의 유튜브 일일 상한은 **아직 실측하지 않았다** — 2·3단원을 올려 보고 적는다.
- **발행 자동화** — 발행 저장소 토큰 권한이 없어 신호가 HTTP 403 으로 막혔으나,
  권한을 더한 뒤 정상 동작을 확인했다. 이제 머지하면 몇 분 안에 사이트에 반영된다
