# 함정

모두 실제로 밟은 것이다. 막히면 여기서 먼저 찾는다.

## NotebookLM

**프롬프트에 줄바꿈이 있으면 대화상자가 닫힌다.**
`fill` 로 여러 줄 문자열을 넣는 순간 설정 창이 사라진다. 한 문단으로 이어 붙여 넣는다.

**`AI 사용량` 창을 닫으면 설정 대화상자까지 닫힌다.**
사용량은 생성을 걸기 전에 따로 확인하고, 설정 창을 열어 둔 상태에서는 건드리지 않는다.

**생성이 실패할 때가 있다.**
7분쯤 뒤 "동영상 개요를 생성할 수 없습니다. 새 소스를 입력해 보세요"가 뜬다.
실패본을 `더보기` → `삭제` 로 지우고 다시 건다. 프롬프트를 짧게 줄이면 통과율이 오른다.

**예약(`나중에 생성`)은 정시에 자동 실행되지 않는다.**
한도 재설정 20분 뒤에도 "4오후 이후로 예약됨" 상태였다. 한도가 풀리면 예약을 지우고
직접 `지금 생성` 으로 건다. 예약 자체도 6건이 상한이었다.

**두 판 중 한 판만 실패하는 일이 있다.**
같은 노트북에 같은 프롬프트로 두 번 걸어도 한쪽만 실패한다. 실패본을 지우고 다시
걸되, 한도가 빠듯하면 성공한 한 판으로 간다. 두 판은 더 나은 것을 고르기 위한
장치이지 필수 조건이 아니다.

**숏폼은 `--style` 을 지정할 수 없다.**
차시마다 스타일이 다르게 나온다(종이공예·만화·실사 혼합). 시리즈 통일감을 만들 방법이
지금은 없다. 길이도 60초를 넘겨 60~95초 사이에서 들쭉날쭉하다.

## 유튜브 Studio

**업로드 대화상자에서 아무 `닫기`나 누르면 전체가 닫힌다.**
영상이 임시본으로 남는다. 되살리려면 `studio.youtube.com/video/<id>/edit` 에서 `초안 수정`.
AI 정책 안내 토스트를 닫으려다 대화상자를 닫은 적이 있다 — 토스트는 그냥 두고 진행한다.

**게시 버튼을 `"게시|저장"` 으로 찾으면 상단의 비활성 `저장` 을 집는다.**
`button "게시"` 를 먼저 찾고, 없을 때만 `저장` 으로 떨어뜨린다.

**재생목록 체크박스는 예외를 던지지만 실제로는 체크된다.**
`Checkbox click did not change checked state` 가 나와도 상태를 다시 읽어 보면 켜져 있다.
try/catch 로 감싸고 예외를 무시한다.

**세부정보 패널은 가상 스크롤이다.**
제목·설명·태그·카테고리 필드가 접근성 트리에서 사라진다. 안 보이면 스크롤 컨테이너의
`scrollTop` 을 옮긴 뒤 다시 스냅샷한다.

**동영상 언어 드롭다운은 한 번에 안 열릴 때가 있다.**
별도 단계로 떼어 재시도한다.

**업로드 직후 videoId 가 안 뜰 수 있다.**
`undefined` 가 나와도 실패가 아니다. 게시를 마친 뒤 `채널 콘텐츠 → Shorts` 에서 읽는다.

## 저장소

**워크플로 파일은 git push 가 거부된다.**
`refusing to allow an OAuth App to create or update workflow ... without workflow scope`.
GitHub 웹 편집기로 올린다. 편집기는 CodeMirror 라 `fill` 이 안 먹으므로
`Set-Clipboard` 로 내용을 담고, **편집기 요소에 포커스를 준 뒤** `Control+a` → `Control+v`.
페이지 전체에 Ctrl+A 가 먹으면 붙여넣기가 안 되니 `Commit changes...` 버튼이
활성화됐는지로 성공을 판단한다.

**`jjam-classroom` 은 CRLF 로 체크아웃된다.**
Node 스크립트가 다시 쓴 파일이 줄바꿈만 다른 변경으로 잡히는 일이 흔하다.
`git diff --stat` 이 비어 있으면 내용은 같은 것이니 **커밋하지 말고
`git checkout -- <경로>` 로 되돌린다.** 남의 사이트 폴더를 건드리면 그 저장소가 재발행된다.

**`scripts/gen-og.mjs` 의 SITES 를 건드렸으면 반드시 한 번 돌려야 한다.**
항목만 추가하고 산출물(og-image.svg)을 안 만들면 CI(공통 파일 일치 확인)가 넘어진다.
`node scripts/gen-og.mjs --check` 로 미리 확인한다.

**공통 파일을 늘릴 때는 `sync-shared.mjs` 의 TARGETS 에도 넣는다.**
스위처·웹폰트는 모든 사이트 폴더에서 글자 하나까지 같아야 하고 CI 가 그것을 막는다.
상류는 `game/` 이다.

## 환경 (Aside)

**Aside 셸은 `PYTHONHOME`·`PIP_PREFIX` 를 자기 런타임으로 걸어 둔다.**
다른 파이썬을 `& $py -m pip` 로 부르면 pip 이 깨지거나(`ColorTriplet.__new__()`)
패키지가 엉뚱한 곳에 깔린다. Aside 에서 쓸 것은 그냥 `pip install` 로 깐다.

**간헐적으로 `[SSL: CERTIFICATE_VERIFY_FAILED] EE certificate key too weak` 가 난다.**
재시도하면 통과한다. 네트워크를 쓰는 스크립트에는 재시도를 넣어 둔다.
`raw.githubusercontent.com` 도 같은 증상이라 GitHub raw 는
`api.github.com/repos/<owner>/<repo>/contents/<path>` 로 우회한다.

**PowerShell here-string 은 CRLF 라 LF 파일에 문자열 치환이 실패한다.**
`$c.Replace(...)` 가 조용히 아무것도 안 바꾼다. 파일 수정은 **Node 스크립트**로 한다.
`edit_file` 도구도 한글 매칭이 깨질 때가 있어(`흐름` → `흰름`) 한글이 든 파일에는 쓰지 않는다.

**REPL 컨텍스트는 데몬이 재시작하면 날아간다.**
프롬프트·메타데이터처럼 다시 만들기 번거로운 것은 세션 tmp 에 JSON 으로 저장해 두고
읽어 쓴다. 함수는 다시 정의하면 되지만 긴 한국어 문자열은 다시 쓰기 아깝다.

**REPL `fs` 와 브라우저 `setFiles` 는 세션 폴더 안만 다룬다.**
작업 폴더의 파일을 쓰려면 세션 tmp 로 복사한다. 반대로 세션 tmp 는 언제 비워질지
모르므로 결과물은 곧바로 작업 폴더로 옮긴다.

**`display()` 만으로는 이미지를 판단할 수 없다.**
저장한 뒤 `read_file` 로 열어야 실제로 보인다. 검수는 반드시 `read_file` 로 한다.

**스크린샷이 CDP 시간 초과로 실패할 때가 있다.**
`timeout` 을 늘리고 2~3회 재시도한다. `fullPage: true` 는 스티키 헤더가 겹쳐 찍히는
일이 있어, 특정 영역은 `clip` 으로 좌표를 주는 편이 낫다.
