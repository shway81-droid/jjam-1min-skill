# 숏폼 생성 프롬프트

NotebookLM 동영상 개요의 "동영상에서 어떤 부분에 집중해야 하나요?" 칸에 넣는다.
**줄바꿈을 넣으면 대화상자가 닫힌다.** 아래 내용을 한 문단으로 이어 붙여 넣는다.

## 골격

```
초등학교 {학년}학년 {학기}학기 {과목} 교과서 {단원}단원 「{차시명}」 차시입니다.
초등학생이 보는 60초 영상으로, 교과서에 있는 내용만 쓰고 교과서에 없는 내용을
지어내지 마세요. {용어 나열} 같은 용어는 다른 말로 바꾸지 마세요. 초등학생이
모르는 어려운 한자말을 새로 만들지 말고 교과서에 나온 쉬운 말을 쓰세요. 교과서에
나온 집·도구·유물의 모양대로 그리고, 그 시대에 없던 물건을 그리지 마세요. 지도는
이 소스 안에 있는 교과서 지도만 그대로 활용하고, 지도를 스스로 새로 만들거나
그리지 마세요. 사람은 모두 우리나라 사람으로 그리고 서양이나 중국의 옷·갑옷·왕관을
입히지 마세요. 화면에 보이는 글자는 모두 한국어로 맞춤법을 정확히 쓰고 영어를
장식이나 그림 속 이름표로도 넣지 마세요. {다룰 내용을 순서대로} 초등학생의 흥미를
끄는 질문으로 시작하세요.
```

길이는 500~600자가 적당하다. 더 길게, 금지 조항을 여러 줄로 늘어놓은 판은
생성이 실패한 적이 있다.

## 각 조항이 들어간 이유 (실측)

| 조항 | 없앴을 때 일어난 일 |
|---|---|
| 교과서에 있는 내용만 | 없던 사실을 만들어 넣는다 |
| 용어를 바꾸지 마라 | 고유명사를 다른 말로 바꾼다 |
| 어려운 한자말을 만들지 마라 | 04차시가 "잉여 생산물"을 썼다. 5학년에게 어렵다 |
| 교과서에 나온 모양대로 | 04차시에서 움집 대신 기둥 위 곡식 창고가 나왔다 |
| **지도는 교과서 지도만** | 06차시에서 한반도가 육각형 도형으로 나왔다. 이 조항을 넣은 뒤 10·13차시는 실제 한반도 모양이 나왔다 |
| **사람은 우리나라 사람으로** | 04차시에 로마 병사, 06차시에 서양식 왕관을 쓴 백인 왕, 06차시에 중국풍 성벽, 19차시 원성왕릉 무인상이 로마 병사처럼 나왔다 |
| 화면 글자는 한국어 | 영어 도장·라벨을 장식으로 찍는다. 04차시 다이어그램에 `Copper ore` `Stone crucible` 같은 영어 이름표가 5개 찍혔다 — "그림 속 이름표로도"라는 말을 넣어야 막힌다 |

## 용어 나열은 차시 본문에서 뽑는다

차시 PDF에서 텍스트를 뽑아 **교과서가 굵게 다루는 낱말**을 5~8개 고른다.
앞 차시 목록을 그대로 두면 엉뚱한 낱말을 지키느라 힘을 쓴다.

```python
import pymupdf
d = pymupdf.open(pdf)
print("\n".join(p.get_text() for p in d))
```

## 유튜브 설명문 골격

제목 끝에 `(1편)` `(2편)` 을 붙인다. 설명문은 두 편이 같아도 된다.

```
초등학교 {과목} {학년}학년 {학기}학기 {단원}단원 {N}차시 「{차시명}」를 1분으로 정리했습니다.

수업 도입에 틀어도 좋고, 시간이 남을 때 복습으로 써도 좋습니다.

다루는 내용
{한 줄 요약}

짬짬이 1분 수업 - 교과서 차시를 1분으로

#초등사회 #사회5학년2학기 #짬짬이1분수업
```

## 같은 프롬프트로 두 판을 뽑는다

프롬프트를 아무리 조여도 결과에 편차가 크다. 같은 프롬프트로 두 번 걸면 한쪽에만
있는 결함이 드러나고, 더 나은 쪽을 고를 수 있다.

**두 판의 프롬프트를 다르게 하지 마라.** 다르게 하면 무엇 때문에 좋아졌는지 알 수 없다.
같은 조건에서 뽑아 **결과의 편차만 고르는 것**이 요점이다.

프롬프트를 고치는 것은 별개의 일이다. 여러 차시에서 같은 결함이 반복될 때만
조항을 하나 더하고, 그 근거를 위 표에 기록한다.

스타일은 차시마다 다르게 나온다(종이공예·만화·실사 혼합). 숏폼은 `--style` 지정이
안 되는 고정 스타일이라 시리즈로서 통일감을 만들 방법이 지금은 없다.
길이도 60초를 넘겨 60~95초 사이에서 들쭉날쭉하다.

**같은 프롬프트로 만든 두 판도 스타일이 서로 다르게 나온다.** 그래서 고를 때
스타일 취향보다 내용 정확성을 먼저 본다.
